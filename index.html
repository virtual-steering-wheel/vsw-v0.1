Quick start

Install and connect

  1. Download and run the Windows installer, or extract the portable ZIP to a folder. The installer is per-user and does not require administrator access.
  2. Install ViGEmBus separately from its official source if you need the virtual Xbox controller. The VSW installer does not install drivers or change firewall settings.
  3. Allow the receiver on your trusted Private network when Windows Firewall asks. Keep the phone and PC on the same reachable network, open the receiver, then use discovery or enter the PC's current IP in the Android app.
  4. In your game, select the VSW virtual Xbox controller and map its controls. For ETS2/ATS live speed, RPM, gear, and damage, install and enable a compatible SCS telemetry plugin.

Streaming frame rate and resolution are best-effort request targets, not guarantees. Telemetry is game/plugin dependent. Verify downloaded files using the SHA-256 values shipped alongside the downloads.
